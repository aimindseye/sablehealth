## Calculation contract v1

- **Sleep:** one selected session at a time. Require nonempty, complete, contiguous, nonoverlapping, recognized stage intervals covering its exact start/end. Sorting is deterministic. Unknown/invalid/gap/overlap means no ratio. Recorded asleep is Light, Deep, REM or generic Sleeping. Awake-in-bed is in-bed but not asleep; Out-of-bed is excluded from the in-bed denominator. Generic Awake does not establish in-bed location, so report only the separate asleep/session percentage and withhold in-bed estimate. If no in-bed time, withhold the in-bed ratio (no division by zero). A fully awake-in-bed partition can legitimately yield zero. Use fractional seconds; display one decimal via locale number format. Explicitly identify stage-derived estimate, writer package, calculation version and denominator. No clinical thresholds; no scoring from partial data.
- **HR bands:** manual maximum in whole BPM 1–300, optional manual resting in 1..maximum-1; these are mathematical input bounds, not safe-exercise recommendations. Maximum-only boundaries = maximum × p; HR-reserve boundaries = rest + (maximum − rest) × p. Fixed illustrative 50/60/70/80/90/100% boundaries; not training prescription or validated individual zones. No age-predicted maximum, default personal values, auto-imported resting value, workout detection or time-in-zone estimate. Invalid/absent inputs produce no result. Inputs are ephemeral Compose state, cleared by Clear inputs or closing the section. Calculator is available in Move even without a Health Connect snapshot or in Demo/No records; manual inputs remain separate from measurement history.
- **History:** retain existing aggregate daily/hourly steps, 7/30-day calendar, observed-only means excluding today, sleep wake-day grouping/nonoverlap and stage geometry, actual HRV RMSSD/RHR series, null gaps and existing source decisions. Expand Method and sources for status, method, date/value/writer of each observed point. Distinguish latest sample vs daily average, reported RMSSD vs recomputed HRV, session span vs asleep. No SDNN conversion, RR inference or interpolation. No source-fusion or priority changes; M3 remains separate. Dashboard retains four daily slots and approved chrome.
